# ผลประเมิน SQL และการตรวจคำอธิบาย

## ความถูกต้องของ SQL

รันจริงด้วย Spark อ่านข้อมูล HDFS ใช้ OPA และ Qwen ผ่าน Ollama แล้วเทียบตารางกับผลจาก Gold SQL ที่รันแยกบนข้อมูลเดียวกัน

| ชุดที่รัน | รวม | ไทย | อังกฤษ |
|---|---:|---:|---:|
| SQL ในชุดพัฒนา ก่อนแก้ | 144/160 | 71/80 | 73/80 |
| ขอสูตรในชุดพัฒนา | 24/24 | 12/12 | 12/12 |
| ควรถามกลับในชุดพัฒนา | 16/16 | 8/8 | 8/8 |
| โจทย์เดิมหลังแก้ (ก่อนแก้ 11/16) | 16/16 | 8/8 | 8/8 |
| โจทย์ใหม่หลังแก้ | 11/12 | 5/6 | 6/6 |

ชุดพัฒนา 200 ข้อยังไม่ได้รันซ้ำหลังแก้รอบนั้น โจทย์ใหม่ 12 ข้อมาจาก 6 โจทย์หลักในสองภาษา ข้อที่พลาดเกิดจากผู้ตรวจปฏิเสธ SQL ที่กรองประเทศร่วมกับการเลือกใบสั่งซื้อที่ไม่มีรหัสลูกค้า

## ชุดทดลองใน Langfuse

เลือกโจทย์ SQL 40 ข้อจากชุดพัฒนา ผล SQL ตรง **36/40** และคำอธิบายผ่านเกณฑ์ **32/40** อีก 8 ข้อไม่มีคำอธิบายให้ตรวจ ตัวตรวจจับข้ออ้างผิดได้ **2/8** ในชุดควบคุม [ผลตรวจหลักฐาน](FAITHFULNESS_EVIDENCE_AUDIT.md)
