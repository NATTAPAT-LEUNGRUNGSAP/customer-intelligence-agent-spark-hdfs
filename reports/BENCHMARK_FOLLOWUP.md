# ผลประเมิน SQL และการตรวจคำอธิบาย

## 1. ผลชุดพัฒนา 200 ข้อ ก่อนปรับกฎ SQL

ตัวเลขในตารางคือ **จำนวนข้อที่ผ่าน / จำนวนข้อที่ทดสอบ** ข้อ SQL ผ่านเมื่อผลจาก Spark ตรงกับผล SQL อ้างอิง (Gold SQL) บนข้อมูล HDFS ชุดเดียวกัน

| สิ่งที่ทดสอบ | รวม | ไทย | อังกฤษ |
|---|---:|---:|---:|
| ผล SQL ตรงกับคำตอบอ้างอิง | **144/160** | 71/80 | 73/80 |
| ตอบสูตรตามที่คาดไว้ | **24/24** | 12/12 | 12/12 |
| ถามกลับหรือแจ้งข้อจำกัดตามเกณฑ์ | **16/16** | 8/8 | 8/8 |

ชุด 200 ข้อนี้ยังไม่ได้รันซ้ำหลังปรับกฎ

## 2. ผลก่อนและหลังปรับ บนโจทย์ SQL ชุดเดียวกัน 16 ข้อ

| ภาษา | ก่อนปรับ | หลังปรับ |
|---|---:|---:|
| รวม | **11/16** | **16/16** |
| ไทย | 5/8 | 8/8 |
| อังกฤษ | 6/8 | 8/8 |

ทั้ง 5 ข้อที่เคยพลาดให้ผลตรงกับ SQL อ้างอิงเมื่อรันซ้ำหลังปรับ

## 3. ผลจากโจทย์ SQL ใหม่ 12 ข้อ หลังปรับกฎ

ผลตรงกับ SQL อ้างอิง **11/12 ข้อ** (ไทย **5/6** อังกฤษ **6/6**) ชุดนี้มี 6 โจทย์หลักในสองภาษา ข้อที่พลาดเกิดจากผู้ตรวจปฏิเสธ SQL ที่กรองประเทศร่วมกับการเลือกใบสั่งซื้อที่ไม่มีรหัสลูกค้า

## 4. คะแนนใน Langfuse จากโจทย์ SQL 40 ข้อในชุดพัฒนา

ผล SQL ตรง **36/40** และคำอธิบายผ่านเกณฑ์ **32/40** ตามกติกาที่นับ 8 ข้อที่ไม่มีคำอธิบายให้ตรวจเป็นไม่ผ่าน ตัวตรวจจับข้ออ้างผิดได้ **2/8** ในชุดควบคุม [ผลตรวจหลักฐาน](FAITHFULNESS_EVIDENCE_AUDIT.md)
