# เปิดเว็บและลองถาม

ใช้ Docker Desktop แบบ Linux containers และ Ollama ที่ container ติดต่อได้ทาง `host.docker.internal:11434` ทำตาม [ขั้นตอนติดตั้ง](../README.md#เริ่มใช้งาน) ค่า `--manifest` ใน Compose ต้องชี้ไปยังไฟล์ `/app/reports/build-<run-id>.json` ที่ build ผ่านบนเครื่องนี้

เปิด [เว็บวิเคราะห์](http://localhost:8090/) แล้วเลือกช่วงเวลาและประเทศ หรือเริ่มจากตัวอย่างบนหน้าเว็บ ค่าเริ่มต้นคือข้อมูลทั้งหมด วันที่สิ้นสุดที่เลือกนับรวมด้วย ช่วงที่ระบุในคำถามมีลำดับก่อนตัวเลือกบนเว็บ

- **Dashboard** แสดงยอดขาย ใบสั่งซื้อ มูลค่าเฉลี่ยต่อใบ และจำนวนผู้ซื้อที่มีรหัส พร้อมกราฟตามตัวกรอง
- **ถาม AI** ใช้ RAG และ SQL ที่ Agent สร้าง เปิด SQL หลักฐาน และ trace ใต้ผลได้
- **ถามต่อเนื่อง** ใช้คำถามก่อนหน้าที่ตอบสำเร็จเพื่อแก้ช่วงเวลาที่รองรับ เช่น “แล้วเดือนก่อนล่ะ”
- **ดูคอลัมน์** พิมพ์ “มีคอลัมน์อะไรบ้างในฐานข้อมูล” ระบบแสดงชื่อและชนิดข้อมูลจาก schema ที่โหลด

ตรวจว่าเว็บพร้อมจาก [สถานะ API](http://localhost:8090/api/status) ถ้าเปิดไม่ได้ ให้ดู `docker compose -f compose.yaml -f compose.web.yaml --profile web logs --tail 30 web` ใช้คำสั่งเดียวกันโดยเปลี่ยนท้ายเป็น `stop web` เมื่อต้องการหยุดเว็บ

เว็บรับงานทีละคำถามและเก็บ trace ใน `reports/web-agent-*.json` ซึ่งอาจมีคำถามและผลรายลูกค้า [วิธีแชร์ชั่วคราว](FRIEND_ACCESS.md) · [เส้นทาง API และโค้ด](CODE_HANDOFF.md)
