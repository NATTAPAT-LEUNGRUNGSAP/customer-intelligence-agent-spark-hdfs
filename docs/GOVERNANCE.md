# นิยามธุรกิจและกฎตรวจ

[RDF/OWL](../ontology/) เชื่อมคำธุรกิจกับสูตรและตาราง ตัวอย่างเช่น จำนวนใบสั่งซื้ออิง `orders` ซึ่งหนึ่งแถวแทนหนึ่งใบสั่งซื้อสำเร็จ SHACL ตรวจโครงสร้างกราฟ เช่น ตัวชี้วัดต้องอ้างอิงตารางต้นทางที่ระบุไว้

| จุดตรวจ | ตรวจอะไร |
|---|---|
| ก่อนรัน | SQL อ่านอย่างเดียว ตารางและฟังก์ชันที่อนุญาต สูตร ช่วงเวลา หลักฐาน และคำตัดสิน OPA |
| หลังรัน | โครงสร้างตาราง ค่าตัวเลข สัดส่วน กลุ่มซ้ำ และคำตัดสิน OPA ก่อนคืนผล |
| ตอนประเมิน | เทียบผล Spark กับ Gold SQL ที่รันแยกบนข้อมูลเดียวกัน |

Rego คือภาษาที่ใช้เขียน [กฎ OPA](../policies/) หาก OPA ติดต่อไม่ได้ Agent หยุดตามนโยบาย [จุดตรวจในโค้ด](TOOL_HOOKS.md) · [ผลประเมิน](../reports/BENCHMARK_FOLLOWUP.md)
