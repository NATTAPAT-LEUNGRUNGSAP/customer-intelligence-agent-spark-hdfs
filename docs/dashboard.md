# Dashboard ยอดขายและลูกค้า

ตัวกรองช่วงเวลาและประเทศใช้ร่วมกันระหว่าง Dashboard กับช่องถาม AI โดยช่วงที่ระบุในข้อความมีลำดับก่อนตัวเลือกบนเว็บ

Dashboard ใช้ SQL ที่ระบบกำหนดไว้เพื่อคำนวณยอดขาย ใบสั่งซื้อ มูลค่าเฉลี่ยต่อใบ และผู้ซื้อที่มีรหัส ส่วนช่องถาม AI ให้ Agent สร้าง SQL เอง ทั้งสองเส้นทางใช้ Spark และตรวจนโยบายด้วย OPA

กราฟ RFM เลือกผู้ซื้อจากช่วงเวลาและประเทศที่กำหนด แล้วเทียบกับกลุ่มลูกค้า ณ snapshot ที่มีอยู่ ส่วนอันดับสินค้าอิงรหัสสินค้าและอาจมีรหัสรายการพิเศษจากข้อมูลต้นทาง
