# จุดตรวจก่อนและหลัง Spark

[ToolHooks](../jobs/tool_hooks.py) เป็นตัวกลางที่ Agent และ Dashboard ใช้รอบการเรียก Spark SQL ส่วนการตรวจ syntax ความหมาย และหลักฐานของ Agent เกิดก่อนเข้าจุดนี้

| จุดตรวจ | พฤติกรรม |
|---|---|
| `before_tool` | ขอคำตัดสินจาก OPA ถ้าไม่ผ่านจะหยุดก่อนรัน |
| `after_tool` | ตรวจตารางผลและนโยบายก่อนคืนคำตอบ |
| `on_error` | รองรับฟังก์ชันสังเกตข้อผิดพลาดเพิ่มเติม ระบบบันทึกขั้นที่ล้มเหลวใน `hook_trace` อยู่แล้ว |

ข้อผิดพลาดที่แก้ได้จะกลับเข้าวงรอบแก้ SQL ของ Agent ซึ่งมีงบรวมสามรอบ การตรวจผลดูเงื่อนไขที่รองรับ ส่วนความถูกต้องของคำตอบวัดด้วย Gold SQL แยกใน [ชุดประเมิน](../evaluation/README.md)
