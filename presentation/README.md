# Presentation

Current deck: [customer-intelligence-visual-guide.pptx](customer-intelligence-visual-guide.pptx), 19 slides in Thai/English.

Editable diagrams explain the business question, architecture, data pipeline,
Prompt/Context/Harness/Loop, RAG, knowledge definitions, SQL guards, repair loop,
web interface, evaluation and measured outcomes. Slide labels omit release and
software version numbers and delivery time-box framing.

Historical pre-context measurements and context experiments remain separate.
Both context comparison groups use RAG. The results do not establish a general
solution to model-internal context rot. Architectures from the reference images
are not presented as implemented features.

The deck uses native editable shapes, connectors, text and tables. Supplied
reference images are inspiration and are not embedded or published. Exported
text and source notes are in outline-visual-guide.ndjson. Earlier decks remain.
All slides were rendered and visually reviewed, including revised arrows and
labels. The file was not opened in Microsoft PowerPoint.

Demo: start the stack, open localhost:8090, ask the October 2011 invoice count,
inspect SQL/evidence/trace, then demonstrate a missing-period clarification.
The web-use slide is a process diagram, not a screenshot of a newly run demo.
